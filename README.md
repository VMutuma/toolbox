# Toolbox

A collection of small scripts, tools, and experiments that don't warrant their own dedicated repo. Each subfolder is a self-contained mini-project — see its own README (if present) for specifics.

| `suss-with-sanity` | — | Active |
| `Lead-Analyzer` | Analyzes and scores leads from CRM exports | Active |
| `Sendy-Toolkit` | Utilities for working with Sendy email campaigns | Active |

## Adding a new project

1. Create a new folder named after the project.
2. Drop the code in.
3. Add a row to the table above with a one-line description.
4. If the project needs setup/usage notes, add a short `README.md` inside its own folder.

## Notes

This repo is a working collection — expect it to grow over time as new small projects get added.
